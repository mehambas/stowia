# Changelog

## 0.1.0

First public release.

- Clipboard history in a panel under the menu bar icon: ⌘⇧V, search, Return pastes into the previous app (with Accessibility access) or copies, ⇧Return pastes as plain text, ⌘→ shows the full content.
- Text with its formatting, links, PNG and TIFF images with thumbnails and previews, and the locations of copied files.
- Search in content, names and source apps, with several words and without typing accents.
- Favorites that the limits never delete, names for clips, and a library window with large previews.
- Privacy: content marked as concealed, transient or auto-generated is skipped, password managers are excluded by default, and any app can be excluded. Pause, Clear Last Hour and Clear History.
- Limits for age, count and size; favorites don't count.
- Update check: once a day Stowia asks GitHub for the latest version number, and nothing about you or your clipboard is sent. Download and Install verifies the disk image, opens it and quits Stowia so you can drag the new version to Applications.
- Open at login, in Settings › General.
- English and Turkish.
